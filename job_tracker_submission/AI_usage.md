Ai usage documentation:

Course: COP4751 – Database Systems
Project: Job Application Tracker

I used ChatGPT to assist with planning, developing, debugging, and improving my Job Application Tracker project. ChatGPT helped me understand how Python, Flask, MySQL, HTML, and CSS work together to create a full-stack database application. I also used ChatGPT for troubleshooting errors, developing the user interface, and understanding how to test the application.

Prompts:
1. Requests for help connecting a Flask application to my MySQL database.
2. Requests for help understanding and debugging errors while running the Flask application.
3. "Update what I have already."
4. Requests to verify the Job Match feature and its matching percentages.

What Worked:

ChatGPT assisted in creating and organizing Flask routes for displaying database records, adding new records, editing existing records, and deleting records, this helped me build the CRUD functionality required for the Companies, Jobs, Applications, and Contacts tables.
AI assistance helped me understand how to connect Flask to MySQL, retrieve records, and display database information on web pages.
I also learned more about database connections, SQL queries, and how the backend communicates with the database.
ChatGPT assisted with implementing the skills-matching functionality. The feature compares skills entered by the user against the skills required by jobs stored in the database.
It displays matching percentages and identifies matching and missing skills.
ChatGPT helped create and modify the HTML and CSS used throughout the application, including the dashboard, forms, tables, buttons, navigation bar, and job matching page.
ChatGPT helped me troubleshoot development issues, including MySQL connection errors and problems running the Flask server on my Mac.
It explained possible causes and provided steps for resolving these issues.

What I changed:

Although ChatGPT assisted with code generation and troubleshooting, I made decisions about how I wanted the application to look and function.
I used environment variables to keep my database credentials separate from the source code.
I manually tested the CRUD functionality for all four tables. For example, I added a company, edited its information, and deleted the test record.
I reviewed the project files and prepared the necessary source code and documentation for submission through GitHub.

Lesson learned:

This project helped me understand both full-stack development and the responsible use of generative AI.
I learned that code suggested by AI should not automatically be assumed to work. It needs to be tested with the actual database, project files, and local environment.
I encountered problems involving database credentials and the Flask server. Troubleshooting these issues helped me understand how different parts of the application depend on one another.
When I explained exactly what I wanted, such as changing the website from blue and white to red and white without changing its functionality, the assistance became more specific and useful.
ChatGPT helped with code, explanations, and troubleshooting, but I still needed to configure my environment, run the application, test its features, and verify that it met the project requirements.
